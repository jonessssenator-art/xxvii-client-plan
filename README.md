# XXVII - план и ежедневные отчеты

Дашборд: https://jonessssenator-art.github.io/xxvii-client-plan/

Основные данные: data/dashboard.json. Архив по датам: data/reports/. GitHub Pages публикует папку docs из main.

Ежедневная работа запускается в 19:00 МСК локальным планировщиком macOS на компьютере владельца. Требуется включенный Mac, интернет и действующая авторизация Codex/GitHub. Процесс исследует запросы, обновляет отчет, собирает docs и отправляет изменения в GitHub. Секреты в репозитории не хранятся. Если запуск сорвался, он не должен выдавать старый отчет за новый.

Проверки доступности источников сохраняются отдельно в data/daily/ и не считаются поиском клиентов или отправкой сообщений. Исходные факты: отправок 0, ответов 0, продаж 0, оплат 0.

Личные отметки браузера остаются локальными; публичные отчеты читаются из репозитория. Не публиковать закрытую переписку и непубличные данные клиентов.
